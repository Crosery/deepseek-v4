Architecture

重新定义注意力

混合注意力机制

压缩稀疏注意力 (CSA) 与深度压缩注意力 (HCA) 协同工作——在百万 Token 上下文中，推理 FLOPs 仅需 DeepSeek-V3.2 的 27%，KV Cache 占用降至 10%。长文本不再是奢侈品，而是默认能力。

流形约束超连接

mHC 强化残差连接中的信号传播，从架构层面解决深层网络的训练稳定性问题。更深、更稳、更强——不再依赖工程 trick 补偿。

Muon 优化器

基于矩阵正交化的新型优化器，在万亿参数规模下实现更快的收敛速度和更稳定的训练曲线。更少的步数，更好的结果。

Reasoning

三种深度

1

Non-think

快速直觉模式。日常问答、文本改写、格式转换——无需深度推理的任务，毫秒级响应。省下的算力留给真正需要思考的问题。

2

Think High

详细逻辑分析模式。数学证明、代码架构设计、多步推理——模型展开完整的思维链条，每一步都可审查、可验证。

3

Think Max

全量推理模式。竞赛级数学、复杂工程问题、长上下文综合分析——释放模型的全部推理能力，冲击当前最优表现。需要至少 384K token 上下文。
